AWS 3-Tier 고가용성 웹 서비스 프로젝트

본 페이지는 Route 53 (www.kms26.cloud) 및 Nginx 웹 서버를 통해 호스팅되고 있습니다.

🏗️ 아키텍처 구성요소 및 실습 내용

  • Web Tier: Nginx Auto Scaling Group (EBS 마운트: /mnt/data/www)
  • WAS Tier: FastAPI (api.kms26.cloud, EBS 마운트: /mnt/data/fastapi-app)
  • DB Tier: MySQL EC2 (EBS 10G 디스크 파티셔닝 후 /mnt/data/mysql 및 /mnt/log/mysql 세팅)
  • Storage: S3 버킷을 통한 정적 파일(HTML, Python Script) 관리 및 동적 배포

🔗 서비스 테스트 링크

아래 버튼을 클릭하면 FastAPI 백엔드를 거쳐 MySQL DB와의 연동 상태를 실시간으로 확인하는 페이지로 이동합니다.
